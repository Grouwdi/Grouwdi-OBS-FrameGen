Grouwdi-OBS-FrameGen 1.0.0 - manual install
(Or run Grouwdi-OBS-FrameGen-1.0.0-Setup.exe, which does all of this for you.)

1. Close OBS.
2. If you used an earlier build, delete its folder first. Either or both of:
      C:\ProgramData\obs-studio\plugins\capture-smoother
      C:\ProgramData\obs-studio\plugins\Grouwdi-OBS-CaptureSmoother
   (Same internal filter IDs: OBS cannot load two of them. Your filters and settings are kept.)
3. Copy the "Grouwdi-OBS-FrameGen" folder from this zip into
      C:\ProgramData\obs-studio\plugins\
   (paste that path into File Explorer's address bar; administrator rights needed).
   You should end up with:
      C:\ProgramData\obs-studio\plugins\Grouwdi-OBS-FrameGen\bin\64bit\Grouwdi-OBS-FrameGen.dll
4. Start OBS. Help > Log Files > View Current Log should show
      [Grouwdi-OBS-FrameGen] loaded (version 1.0.0)
5. Pan the camera for a few seconds once, so the flow direction is calibrated and saved.

Setup and settings: see README.txt.
